Вход в TikTok

              
              
              
              
Создайте отдельный вход приложения через обычный Google Chrome. При работе по расписанию браузер останется скрытым.

              
    
                
  1. Остановите worker и нажмите «Открыть Chrome для входа».
    2. 
                
  2. В открывшемся отдельном окне вручную войдите в TikTok. Входить в аккаунт Google или включать синхронизацию Chrome не требуется.
    3. 
                
  3. Убедитесь, что открываются ваши сообщения, и закройте это окно Chrome.
    4. 
                
  4. Нажмите «Проверить вход». Приложение выполнит одну скрытую проверку без отправки сообщений.
    5. 
              

              
              
              
              

              
Основная сессия Chrome не копируется. При первом переходе прежний профиль приложения заменяется только после успешной проверки. Если вход позже завершится, используйте эти же кнопки: приложение откроет сохранённый отдельный профиль.

              

                Перенос существующей сессии через cURL
                

              
Этот способ копирует сессию обычного Chrome. При одновременном выходе на нескольких устройствах используйте отдельный вход выше.

              
    
                
  1. В Chrome с выполненным входом откройте tiktok.com/messages.
    2. 
                
  2. Нажмите F12 → Network (Сеть), затем Ctrl+R.
    3. 
                
  3. Найдите первую строку messages (тип document). Правая кнопка → Copy → Copy as cURL (bash). Если видите только Copy as cURL — выберите его.
    4. 
                
  4. Вставьте скопированное ниже и нажмите «Проверить и сохранить вход».
    5. 
              

              
              
              
Точки скрывают данные входа — это нормально. Если скопирован список запросов, будет прочитан только первый. В Chrome выбирайте строку messages → Copy as cURL.

              
              

              
Проверка занимает до 90 секунд. При успехе создаётся резервная копия текущего входа. Содержимое запроса не сохраняется в логах; поле очищается после отправки.

                

              

              

                Старый способ: копирование профиля Chrome
                

              
Для старых профилей Chrome. Современные защищённые cookies этим способом не переносятся.

              
              
              
              
              
              
              
Перед копированием профиля закройте Chrome и остановите worker.
