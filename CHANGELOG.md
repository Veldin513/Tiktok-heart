# Changelog

## Unreleased — 2026-10-23

- В журнале новые строки отображаются сверху, включая краткий просмотр логов.

- Добавлены создание профиля и адресата в интерфейсе, проверка ссылок и дубликатов, переход к импорту входа для выбранного профиля.
- Worker требует видимый авторизованный интерфейс, прекращает работу при потере сессии/проверке TikTok и не выполняет повторный вход до свежего подтверждённого импорта.
- Отключены автоматический сброс нечитаемого профиля и автоматический переход к QR/паролю. Убраны подмена navigator и флаги маскировки, настройки Chromium согласованы для импорта и работы.

- Добавлен импорт cookies из запроса Chrome без выполнения cURL. Перед заменой профиля вход проверяется в отдельном Chromium; прежний профиль сохраняется в резервной копии.
- Исправлены распознавание входа, откат неудачного переноса и закрытие браузера при self-test.
- Копирование профиля отклоняет недоступные ключи шифрования и cookies Chrome v20.
- Поддержана установка Chromium в `.playwright-browsers` для устранения проблем запуска из AppData.
- Скрипты Windows выбирают проектную `.venv`; README содержит установку с нуля, сборку Tauri и восстановление входа.

## 2.2.0 — 2026-10-15

### Исправления запуска по расписанию

- Сохранённый PID проверяется по пути скрипта и времени создания процесса. Если Windows выдала старый номер другой программе, новый запуск больше не пропускается.
- Блокировка профиля восстанавливается, если указанный в ней PID был повторно использован после завершения worker или перезагрузки.
- При завершении worker очищает собственный PID. Блокировка освобождается даже при ошибке очистки состояния.
- Команда остановки проверяет принадлежность процесса worker перед завершением.
- Флаг остановки сбрасывается до запуска дочернего процесса, чтобы новый worker не прочитал старую команду остановки.
- Тихий launcher переводит параметры `--boot-force`, `--self-test` и `--no-browser` в соответствующие переключатели PowerShell.

### Другие изменения

- Включены накопленные изменения интерфейса, истории запусков, диагностики и управления расписанием.
- Добавлены проверка и восстановление backup авторизации с предварительной резервной копией.
- Разделены службы резервных копий, производительности и расписания; удалён устаревший интерфейс.
- Согласованы версии Python-проекта, Node-пакета и Tauri. Зависимости для проверки кода теперь включают Ruff.

Обновление выполняется в существующей папке проекта. Локальные профили, cookies, токены, логи и резервные копии не входят в публикацию.
