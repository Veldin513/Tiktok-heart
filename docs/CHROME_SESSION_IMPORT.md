# Перенос входа из Chrome без расширений

В приложении откройте «Браузер» → «Импорт из Chrome» и выберите профиль приложения.

1. В обычном Google Chrome откройте `https://www.tiktok.com/messages`. Сообщения должны открываться с вашим аккаунтом.
2. Нажмите F12, выберите Network (Сеть), обновите страницу Ctrl+R.
3. Найдите строку `messages` с типом `document`. Нажмите правой кнопкой → Copy → Copy as cURL (bash). Обычный Copy as cURL также поддерживается.
4. Вернитесь в приложение, вставьте скопированное в поле «Запрос из Chrome» и нажмите «Проверить и сохранить вход».

Команда не выполняется: приложение читает из неё только cookies. Пароли не нужны. Закрывать Chrome не требуется. Worker нужно остановить на время переноса.

Приложение проверит вход в отдельном профиле тем же Chromium, который используется для работы. Адрес страницы `/messages` сам по себе не считается подтверждением: требуется видимый элемент авторизованного интерфейса TikTok. При успешной проверке создаётся резервная копия прежней авторизации, новая сессия становится рабочей и снимается локальная пауза повторных попыток. Worker автоматически не запускается. При ошибке прежний профиль и пауза сохраняются.

Исходный запрос существует только в памяти и не записывается в файлы или логи. Поле очищается после отправки. Не отправляйте скопированный запрос другим людям: он содержит действующую сессию аккаунта.

Cookies сохраняются в локальном профиле браузера с локальным сроком до 30 дней: скопированный заголовок не содержит исходных сроков хранения. TikTok может завершить сессию раньше. В этом случае повторите перенос свежего запроса. Успешный перенос не гарантирует снятие ограничений, установленных самим TikTok.

Если приложение пишет, что cookies входа отсутствуют, убедитесь, что копируете именно запрос `www.tiktok.com/messages`, а не запрос картинки или другого домена. Если вход не подтверждён, проверьте работу сообщений в Chrome и подключение к TikTok. Приложение не выполняет попыток входа с паролем во время проверки.

Официальная документация Chrome о копировании запросов: <https://developer.chrome.com/docs/devtools/network/reference#copy>.
